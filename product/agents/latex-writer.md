# LaTeX Writer

## Mission

Write the final paper in modular LaTeX using only verified evidence.

## Inputs

- `state/problem-map.md`
- `state/modeling-plan.md`
- `state/result-ledger.csv`
- `state/figure-ledger.csv`
- `paper/sections/`

## Outputs

- Updated `paper/sections/*.tex`
- Updated `paper/main.tex`
- Updated `paper/refs.bib`

## Procedure

1. Write model sections after evidence exists.
2. Use motivation, formula, and interpretation for every important equation.
3. Add direct-answer paragraphs for every subquestion.
4. Write the abstract after model sections and validation stabilize.
5. Polish prose without changing verified facts.

## Completion Gate

The paper must answer every subquestion directly and must not contain unverified result claims.

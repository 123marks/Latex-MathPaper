# Figure Quality Checklist

## Purpose

- [ ] Each figure has exactly one primary evidence purpose.
- [ ] The caption states the conclusion, not only the chart type.
- [ ] The body text explains what the reader should learn from the figure.

## Technical Quality

- [ ] Axes have labels and units.
- [ ] Text is readable at paper scale.
- [ ] Vector formats are used for charts where possible.
- [ ] Raster images are high resolution and not stretched.
- [ ] Color choices are restrained and distinguishable.

## Reproducibility

- [ ] Figure appears in `state/figure-ledger.csv`.
- [ ] Ledger identifies script and source data.
- [ ] Script uses relative paths.
- [ ] Generated figure path matches LaTeX `\includegraphics`.

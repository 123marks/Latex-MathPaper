# Paper Quality

Paper OS 产出的是可交付长文档。质量闸门对学术论文、建模赛、工程白皮书同样适用。

## 原则

1. 每个子问题有明确直接答案
2. 重要论断有数/表/图/公式/出处
3. 方法选择说明「为何用、放弃了什么」
4. 公式：动机 → 公式 → 解释
5. 每张图一个证据目的，并在正文解读
6. 假设可辩护且有验证路径
7. 敏感性分析是正文可信度，不是装饰附录
8. 摘要、正文、图、表数字一致

## 图

- 矢量优先 PDF/SVG；必要时才 PNG
- 轴、单位、标签、图注清楚
- 禁默认 matplotlib 花哨样式与无目的饼图
- 图注写证据信息，不只写图表类型

## 反 slop

- 空转场（「首先…然后…最后」而无内容）
- 「效果好 / 合理」却无数
- 引入却不用的公式
- 有图无解释
- 中英摘要事实不一致
- LaTeX/附录里的绝对本地路径

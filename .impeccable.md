## Design Context

### Users

The product serves mathematical modeling competition participants working under time pressure. They need to ingest an official problem, configure an AI provider, coordinate skills/MCP-style tools, produce evidence-backed modeling artifacts, and compile a LaTeX paper without losing traceability.

### Brand Personality

Precise, executive, and alive. The interface should feel like a serious model gateway and research command center, not a toy chatbot, not a Python desktop form, and not a generic AI landing page.

### Aesthetic Direction

The product has two clear surfaces:

- A public-facing homepage that feels like an API/model relay official site: routing, throughput, live signals, animated status rails, provider switching, and a confident product narrative.
- An application workbench entered from the homepage: dense but legible contest controls, stage state, provider setup, material intake, skill/MCP intelligence, and execution logs.

Use a warm ivory, ink, amber, vermilion, and signal-green palette with editorial scientific typography and machine-room motion. Avoid purple-blue AI gradients, glassmorphism as decoration, default system-font blandness, static card piles, and hover-only animation. Motion should continue while idle through rails, particles, scan lines, rotating model rings, signal equalizers, and trace streams.

### Design Principles

1. Split the product into an official-site landing page and a serious app workbench; the user should understand where marketing ends and the application begins.
2. Persistent motion is mandatory. The page must show life even when the cursor is idle, while respecting reduced-motion preferences.
3. Every visual motif should reinforce the product model: routing AI providers, verifying evidence, compiling LaTeX, and packaging submissions.
4. Favor bold hierarchy, asymmetric composition, and precise information density over repeated cards.
5. The executable boundary must stay visible: Windows launcher, local Node app, Python/LaTeX workflow engine, and portable package.
